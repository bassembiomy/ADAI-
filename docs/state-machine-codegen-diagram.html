⚠️ Gotchas for contributors

  1. Never bypass buildSemanticModel — hand-rolled IR skips LCA/exit-entry computation and silently mistargets transitions.
  2. after(ticks) semantics depend on timerPolicy (logical-tick vs actual-delta) + tickMs; keep host vectors, C harness, and target timebase consistent.
  3. Guards/actions must survive smCExpressions lowering — verify new syntax in smExpressions.test and smCGenerator.behavior goldens.
  4. XB-owned states emit SM_XB_*_Init/Enter/Step — changes to XB numerics need xbCConformance/xbDeclaredCConformance re-run.
  5. HIL hardware activity is PENDING without a bench; CI green ≠ hardware proven — check the evidence bundle's per-activity table.
