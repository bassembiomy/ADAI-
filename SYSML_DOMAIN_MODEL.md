# ADIA SysML Domain Model Target

`Project -> SemanticRepository -> elements / relationships / diagrams / presentations -> commands -> validation -> projections`.

Core element families: NamedElement, Package, Classifier, Block, InterfaceBlock, ConstraintBlock, ValueType, DataType, Enumeration, Signal, Unit, QuantityKind, Property, PartProperty, ReferenceProperty, ValueProperty, ConstraintProperty, FlowProperty, Port, ProxyPort, FullPort, FlowPort, Operation, Parameter, Reception, Constraint, Requirement, TestCase, Rationale, Comment.

Core relationships: Generalization, Association, AssociationBlock, Dependency, Connector, ConnectorEnd, NestedConnectorEnd, BindingConnector, ItemFlow, InformationFlow, and typed requirement relationships.

Diagram presentations are view records referencing semantic IDs and never own semantic lifecycle.
