1. Current Design Analysis

The existing panel spans 285 mm × 35 mm — a wide membrane keyboard housing 20 dedicated switches arranged in three rows, each switch backed by an individual LED. The 7-segment display shows time (H:MM) in the centre-left. The panel lists all modes visually at once, relying on the user's ability to scan and memorise 13 cooking modes plus 7 utility controls.

Design Problems Identified

The current architecture has several structural weaknesses that a premium redesign must solve:

Cognitive overload: 13 mode labels are visible simultaneously. A new user faces a wall of text before they can begin cooking. Premium appliances (Breville Joule, Wolf steam oven) hide complexity behind progressive disclosure.

Redundant controls: A dedicated Temp/Time toggle button exists solely to switch which parameter Up/Down adjusts. This is a pure UX debt — a rotary encoder eliminates it entirely.

Dedicated Select button: Unnecessary when a push-button encoder press can serve as confirm. This is the exact UX model used by BMW iDrive, Sonos, and Nest thermostats.

Dedicated Menu button: Menu navigation can be accessed via a long press or secondary encoder context — no discrete switch required.

PCB cost: 22 switches + 16 LEDs = 38 discrete components requiring individual PCB footprints, soldering, and trace routing. Each tactile switch adds ~$0.04–0.08 BOM cost; the matrix decode logic requires an MCU with sufficient GPIO pins or a dedicated keyboard controller IC.

6. Final Recommendation

Verdict: Migrate to the rotary encoder architecture.

The current 22-switch membrane panel is a functional product that works — but it is not a premium product. It reads as budget engineering dressed up with food photography icons. Every high-end appliance in the comparison set (Breville Smart Oven Air Fryer Pro, Ninja Foodi, Instant Pot Pro) has progressively moved toward encoders, OLED displays, and reduced physical switch counts.

Localisation13 physical text labels (Arabic + EN)All labels on OLED — software onlyRotary ✓
AccessibilitySmall icons, no tactile differentiationTactile encoder, large display textRotary ✓

The only genuine risk is discoverability of the 13 cooking modes — users must understand that rotating the encoder scrolls through them. This is mitigated by a clear OLED mode name display, a mode icon strip, and the now-standard consumer expectation of "turn to select" interaction. A simple onboarding animation at first power-on resolves any remaining ambiguity.

The localisation benefit alone justifies the migration: all mode names, unit labels, and menu strings live in firmware. Changing from Arabic to English, or adding new markets, requires zero PCB respins.
